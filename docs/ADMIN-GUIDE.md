# Руководство администратора

## Яндекс Метрика

### Подключение: что занести

Код счётчика в шаблоне уже есть (`src/components/Metrika.tsx`): не хватает только номера счётчика заказчика.

1. Зайдите на [metrika.yandex.ru](https://metrika.yandex.ru) под Яндекс ID заказчика → «Добавить счётчик».
2. Заполните: имя счётчика — название сайта; адрес сайта — боевой домен (тот же, что в `NEXT_PUBLIC_SITE_URL`); часовой пояс — Москва. Примите условия и создайте счётчик.
3. **Вебвизор не включайте.** Он записывает ввод в формы, то есть имя и телефон, а в согласии на обработку данных этого нет. Остальное (карта кликов, внешние ссылки, точный показатель отказов) сайт включает сам.
4. Код счётчика со страницы установки копировать в сайт **не нужно**: сайт подключает счётчик сам, и только после «Принять все» в баннере cookie. Картинку `<noscript>` из кода Метрики не добавляйте: она ставит cookie без согласия.
5. Номер счётчика (цифры над графиком или в списке счётчиков) впишите в одно место:
   - `src/content/company.ts` → `metrikaId: '98765432'` — номер хранится вместе с данными компании;
   - или переменная `NEXT_PUBLIC_METRIKA_ID` на Vercel (Settings → Environment Variables), если номер разный для тестового и боевого сайта. Переменная главнее поля.
6. Пересоберите сайт (на Vercel — Redeploy): номер встраивается при сборке.
7. Создайте цели из таблицы ниже: в счётчике «Цели» → «Добавить цель» → тип «JavaScript-событие» → идентификатор ровно как в таблице. Названия пунктов меню Метрики со временем меняются — ищите раздел «Цели» в настройках счётчика.
8. Проверьте: `pnpm ready` (номер — только цифры), затем откройте сайт с `?_ym_debug=1` в адресе, нажмите «Принять все» и пройдите калькулятор: в консоли браузера (F12) появятся строки об отправке целей. В отчётах Метрики данные появляются с задержкой до нескольких минут.

Когда номер задан, баннер cookie, страница `/cookies`, политика и согласие сами упоминают Метрику и ClientID (`src/content/legal.ts`). Если посетитель потом выберет «Только необходимые», сайт удалит cookie Метрики и перезагрузит страницу уже без счётчика.

### Цели

Создайте цели типа «JavaScript-событие» с такими идентификаторами:

| Идентификатор | Когда срабатывает | Параметры |
|---|---|---|
| `lead_submit` | Сервер принял заявку. При ошибке отправки цель не срабатывает | `source` — откуда заявка, `variant` — вариант страницы |
| `calc_interact` | Первое изменение в калькуляторе за визит | — |
| `quiz_start` | Первый ответ в квизе | — |
| `quiz_complete` | Квиз пройден, показана вилка цены | — |
| `pdf_download` | Скачана смета после заявки или открыт образец договора или сметы | `doc` — `smeta` или имя файла |
| `phone_click` | Клик по телефону | — |
| `messenger_click` | Клик по Telegram, MAX, ВКонтакте или WhatsApp (прямая ссылка) или по кнопке мессенджера в шапке | `channel` — `telegram`, `max`, `vk`, `whatsapp` или `form` |
| `project_open` | Открыто окно проекта: кликом или по ссылке `/?project=…` | `slug` |

Код целей — `src/lib/analytics.ts` (`track`), счётчик — `src/components/Metrika.tsx`. Клики по телефону, PDF и мессенджерам ловит один обработчик на странице. Новая кнопка получает цель автоматически, если это ссылка `tel:`, ссылка на `.pdf` или элемент с атрибутом `data-messenger`.

### Составная цель-воронка

«Путь к заявке» — составная цель из трёх шагов:
1. `project_open`
2. `calc_interact`
3. `lead_submit`

### Параметры визита

`variant` — вариант первого экрана под рекламу (`default`, `fachwerk`, `monolith`, `scandi`). По нему сравниваются кампании Директа.

### Связь с CRM

Вместе с заявкой в Битрикс24 и 1С уходит ClientID Метрики: строка «ClientID Метрики» в комментарии к лиду и поле `clientId` в JSON для 1С. По нему в Метрику загружаются офлайн-конверсии: квалифицированный лид, встреча, договор. Так Директ учится на заявках, которые дошли до продажи.

## Смета в PDF

После заявки из калькулятора, карточки пакета или окна проекта человек получает кнопку «Скачать смету (PDF)». Ссылка живёт 7 дней и подписана ключом `SMETA_SIGNING_SECRET`. Без ключа в режиме client ссылки не будет, `pnpm leads:check` об этом предупредит.

## Мессенджеры

Кнопки Telegram, MAX, ВКонтакте и WhatsApp в контактах и в окне «Свяжитесь с нами» — прямые ссылки: щелчок открывает чат в новой вкладке, без формы. Ссылки задаются в `src/content/company.ts` → `messengers`:
- **Telegram:** `https://t.me/<имя аккаунта>` или `https://t.me/+<номер телефона>`.
- **MAX:** ссылка-приглашение из приложения (профиль → «Пригласить друзей»), вида `https://max.ru/u/…`.
- **ВКонтакте:** `https://vk.me/<адрес сообщества>` (сразу открывает сообщения сообщества) или `https://vk.com/<адрес>`.
- **WhatsApp:** `https://wa.me/<номер без «+»>`, например `https://wa.me/79161234567`.

В шаблоне стоят заглушки (номер из нулей, `vk.com/club0`, главная MAX): замените их на ссылки заказчика. Пустая строка убирает кнопку канала. Заглушки в разметку schema.org не попадают, настоящие ссылки ВКонтакте, Telegram и MAX уходят туда как профили компании (`sameAs`). Щелчок по ссылке — цель Метрики `messenger_click`.
