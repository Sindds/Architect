# ARCLINE — лендинг архитектурно-строительного бюро

Одностраничный лендинг вымышленного бюро ARCLINE ESTATE: дома из клееного бруса и монолита с панорамным остеклением в Подмосковье. Проект сделан как реалистичный пример для портфолио — режим `concept`: в футере дисклеймер, страница закрыта от индексации, телефон `+7 (000) 000-00-00`, почта на `example.com`, людей на фото нет.

Контент, цифры и запреты — `docs/CONTENT-SPEC.md`. Исходный прототип — `legacy/` (только для чтения).

## Запуск

Нужны Node 20.9+ и pnpm.

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm build && pnpm start
```

Проверки:

```bash
pnpm check          # typecheck + eslint + lint:content + unit-тесты
pnpm e2e            # Playwright: 390 px и 1440 px, axe; перед запуском — pnpm build
pnpm docs:pdf       # пересобрать PDF-образцы договора и сметы в public/docs
```

Playwright берёт Chromium из `CHROMIUM_PATH`, затем из `/opt/pw-browsers/chromium` (облачный контейнер), иначе — свой браузер: поставьте его командой `pnpm exec playwright install chromium`.

## Что на странице

Порядок блоков — `CONTENT-SPEC.md` §4: шапка → первый экран → почему мы → проекты → кейсы → цены → калькулятор и квиз → как строим → команда → отзывы → документы → вопросы → контакты → футер.

- **Окна проектов и кейсов** открываются по ссылке: `/?project=vista`, `/?case=dom-u-vody`. Esc и «Назад» в браузере закрывают окно.
- **Калькулятор** считает по тем же ставкам, что карточки и окна. `/?calc=titan#calculator` подставляет параметры проекта.
- **Квиз** — 4 вопроса и вилка цены, затем форма.
- **Варианты под рекламу**: `/?v=fachwerk`, `/?v=monolith`, `/?v=scandi` или `utm_content=…` — свой H1 и первый проект уже в HTML, без подмены в браузере. Canonical — `/`.
- **Заявки**: Server Action с проверкой полей (zod), ловушкой для ботов, минимальным временем заполнения и лимитом 5 заявок за 10 минут с одного IP.
- **Юридические страницы**: `/privacy`, `/soglasie`, `/cookies` (шаблоны концепта) и 404.

## Заявки

- `concept` — персональные данные не сохраняются: посетитель видит номер заявки и пометку, что это концепт.
- `client` — заявка дописывается в `.data/leads.ndjson` на сервере (сервер — в РФ, 152-ФЗ).
- Если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, в Telegram уходит только номер заявки, источник и вариант — без имени и телефона.

Переменные окружения — `.env.example`.
