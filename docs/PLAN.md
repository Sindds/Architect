# PLAN — лендинг ARCLINE уровня 150 000 ₽+

Документ для Claude Code и для Дмитрия. Контекст и правила — в `CLAUDE.md`, контент и цифры — в `docs/CONTENT-SPEC.md`.

Продукт — **одностраничный лендинг**. Отдельных страниц проектов и кейсов нет: они открываются в модальных окнах со своей ссылкой. Отдельно существуют только обязательные юридические страницы и 404.

---

## 0. Как работать с планом (для Дмитрия)

1. Распакуйте архив и откройте папку в Claude Code. `CLAUDE.md` подхватится автоматически.
2. Фаза **S** (стратегия и тексты) — ваша, делается с Claude в чате до кода. Её результаты Claude Code использует как ТЗ.
3. Каждую задачу с кодом запускайте одним промптом:
   > Прочитай CLAUDE.md и в docs/PLAN.md задачу **P1.2**. Сначала покажи план и список файлов. Жди моего «ок». Затем реализуй, прогони проверки из «Готово, если», покажи их вывод и сделай коммит.
4. После каждой задачи у вас есть видимый результат: файл, блок на странице, зелёная проверка, коммит. Отметьте `[x]` в этом файле.
5. Если Claude Code предлагает что-то вне плана — просите сначала обновить план.

Порядок: S → P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7 → P8 → P9 → (P10 — только с реальным заказчиком).

## 1. Почему лендинг может стоить 150 000 ₽+ и что для этого нужно

### Что говорит рынок
- Лендинг у фрилансера — 30–80 тыс. ₽; с уникальным дизайном, CRM и SEO — 50–80 тыс. ₽ ([vc.ru, 19.03.2026](https://vc.ru/dev/2802478-chestnye-tseny-na-razrabotku-sayta)).
- Лендинг до 100 тыс. ₽ — уровень фрилансера или начинающей студии ([vc.ru, 12.03.2026](https://vc.ru/dev/2791814-skolko-stoit-sait-v-2026-godu)).
- Кастомный лендинг — «от 80 000 ₽ и выше» ([Workspace](https://workspace.ru/landing-page/); дата этой оценки на странице не указана).
- Лендинг — 5 000–150 000 ₽ ([Timeweb / Аспро, 27.03.2026](https://timeweb.com/ru/community/articles/skolko-stoit-razrabotka-sayta-v-2026-godu); статья помечена как реклама).
- Самое дорогое предложение «Лендинг под ключ» в каталоге FL.ru на 08.10.2026 — 130 000 ₽ ([FL.ru](https://www.fl.ru/uslugi-freelancera/landing/)).

**Вывод:** 150 000 ₽ — это верхняя граница рынка лендингов. За «вёрстку красивой страницы» столько не платят. Платят за **лендинг как систему продаж для дорогого продукта**, где видно, за что деньги.

### Логика ценности для заказчика
Минимальный договор в демо-модели — 51 610 000 ₽ (NORDIC под ключ, `CONTENT-SPEC.md` §5.2). Лендинг за 150 000 ₽ — это 150 000 / 51 610 000 = **0,29%** одного договора. Заказчик окупает его одной сделкой. В режиме client считать по реальным ценам заказчика.

### Девять компонентов, которые продают цену (каждый — фаза плана)
1. **Стратегия:** конкуренты, сегменты, карта возражений, оффер, смысловой прототип (S).
2. **Тексты** под каждое возражение, с доказательствами (S).
3. **Авторский дизайн:** концепт первого экрана в двух вариантах и выбор, затем вся страница (P2).
4. **Интерактив, который собирает заявки:** калькулятор, квиз, смета в PDF, окна проектов с планировками (P3, P5).
5. **Конвейер заявок:** БД в РФ → CRM → уведомление → цели Метрики, антиспам, UTM (P4).
6. **Мультилендинг:** разный первый экран под разные рекламные кампании, A/B-тест заголовка (P6).
7. **Админка:** заказчик сам меняет цены, проекты, отзывы, тексты, видит заявки (P1).
8. **Измеримое качество:** Lighthouse, доступность, скорость, 152-ФЗ, 168-ФЗ (P7, P8).
9. **Сопровождение 30 дней:** два цикла улучшений по данным Метрики и отчёт (P10).

## 2. Архитектура

| Решение | Почему |
|---|---|
| Next.js App Router, страница статически сгенерирована | Контент в HTML: Яндекс рендерит JS только «на усмотрение робота» ([справка](https://yandex.ru/support/webmaster/ru/yandex-indexing/rendering)); `next/image` и `next/font` решают проблемы скорости из legacy |
| Payload CMS 3 в том же приложении | Админка на русском, медиа, роли, без отдельного сервера. Требования Payload: Node 20.9+, Next 15.4.11–15.4.x или 16.2.6+, pnpm ([docs](https://payloadcms.com/docs/getting-started/installation)) |
| Postgres на VPS в РФ | Ч. 5 ст. 18 152-ФЗ: первичный сбор ПДн граждан РФ — в базы на территории РФ |
| Заявки через Server Action | Payload занимает `/api/[...slug]`, Server Action не конфликтует с его маршрутами |
| В Telegram — только номер заявки и ссылка | ПДн не уходят на зарубежный сервис |
| Один модуль `src/lib/pricing.ts` | H1, карточки, окна, пакеты, калькулятор, квиз и PDF считают одинаково |
| Окна проектов и кейсов вместо страниц | Это лендинг: человек не уходит со страницы, но окно можно открыть по ссылке из рекламы |
| Варианты = статические версии страницы + rewrite | Разный первый экран под кампании без мигания и без потери скорости |
| Только RU, одна тема, только ₽ | В legacy EN, тёмная тема и валюты множили баги и не приносили заявок. EN — отдельная платная опция |
| Без прелоадера | Скорость и LCP |

## 4. Трудоёмкость и цена

Расчёт:
- по ставке 1 500 ₽/ч с буфером 1,3 (1 950 ₽/ч): 91 × 1 950 = **177 450 ₽**, 138 × 1 950 = **269 100 ₽**;
- по средней ставке рынка 1 800 ₽/ч ([Workspace, на 08.10.2026](https://workspace.ru/landing-page/)): **163 800–248 400 ₽**;
- если продать за ровно 150 000 ₽, ваша фактическая ставка: 150 000 / 91 = **1 648 ₽/ч** в лучшем случае, 150 000 / 138 = **1 087 ₽/ч** в худшем.

**Рекомендация (это моё мнение):** называть 160–190 тыс. ₽ за полный пакет. При 150 тыс. ₽ держать объём ближе к нижней оценке часов.

### Как это продавать (структура КП)
Заказчик покупает не «страницу», а результат и снижение риска. В КП перечислить по пунктам:
1. Исследование: 8–10 конкурентов, 3 сегмента, карта возражений.
2. Тексты под каждое возражение, с доказательствами.
3. Два варианта дизайна первого экрана на выбор, авторский дизайн всей страницы.
4. Калькулятор + квиз + смета в PDF — лид-магнит.
5. Заявки в CRM и Telegram, антиспам, UTM, цели Метрики, воронка.
6. 4 варианта первого экрана под рекламные кампании + A/B-тест заголовка.
7. Админка: цены, проекты, отзывы, тексты, видимость блоков, заявки.
8. Скорость (Lighthouse ≥ 90), доступность, 152-ФЗ, русский язык по 168-ФЗ.
9. 30 дней сопровождения: 2 цикла улучшений по данным и отчёт.

Плюс одна строка логики окупаемости: «Лендинг стоит 0,29% от одного договора» (пересчитать на цены заказчика).

### Опции сверх пакета (часы × 1 950 ₽)
- EN-версия через локализацию Payload: 10–14 ч → 19 500–27 300 ₽.
- Анимированный блок «Как строится дом» с прокруткой по этапам (с упрощённой версией при reduced motion): 6–10 ч → 11 700–19 500 ₽.
- amoCRM вместо Битрикс24: 3–5 ч → 5 850–9 750 ₽.
- Подготовка к коллтрекингу (динамическая подмена номера сервисом заказчика): 2–3 ч → 3 900–5 850 ₽.

### Облегчённый пакет «Старт», если 150 тыс. ₽ не согласовывают
Убрать P6 (мультилендинг и A/B, 5–8 ч), P5.4 (PDF, 2–3 ч), P10 (сопровождение, 5–8 ч) и сделать один концепт вместо двух (1–2 ч). Это минус 13–21 ч, итого 78–117 ч → по 1 950 ₽/ч: 152 100–228 150 ₽. Даже облегчённый пакет по времени не опускается ниже 150 тыс. ₽ при вашей ставке. Продавать дешевле имеет смысл только за счёт скорости с Claude Code или как кейс для портфолио — со скидкой отдельной строкой в договоре.

## 5. Риски

| Риск | Что делать |
|---|---|
| Заказчик не видит разницы с лендингом за 60 тыс. ₽ | КП из 9 пунктов + демо этого концепта: окно проекта, квиз → PDF, админка, вариант под кампанию |
| Несовместимость версий Next.js и Payload | P0.1 — сначала документация; версии фиксируются без `^` |
| Claude Code переносит выдумки из legacy | Правило 5 в `CLAUDE.md` + `pnpm lint:content` в `pnpm check` |
| Цифры снова разъедутся | Только `pricing.ts` + unit-тест на §5.2, §5.3, §9 |
| Варианты «мигают» или портят скорость | Только статические версии + rewrite, без подмены в браузере |
| Юридические формулировки | Тексты политики и согласия — от юриста заказчика |
| Хостинг вне РФ | В `DEPLOY.md` — VPS у российского провайдера, S3-хранилище тоже в РФ |
| Портфолио с вымышленной компанией выглядит как обман | Режим concept: дисклеймер, `noindex`, `example.com`, телефон `+7 (000) …`, без сгенерированных лиц |
