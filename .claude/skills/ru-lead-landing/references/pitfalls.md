# Грабли и решения

Каждая строка — реальная ошибка, найденная в проекте ARCLINE.

| Симптом | Причина | Решение |
|---|---|---|
| При любом сбое отправки формы страница заменяется английским экраном Next «This page couldn't load» | Исключение из server action (обрыв сети, 5xx, рассинхрон версий после деплоя, проверка Origin) не перехвачено | `try/catch` вокруг вызова в клиенте → сообщение с телефоном; русские `error.tsx` и `global-error.tsx`; e2e с `page.route` → abort и 500 |
| После ошибки валидации сбрасываются радиокнопки | В React 19 `<form action>` сбрасывает форму после ответа | `onSubmit` + `startTransition(() => formAction(fd))`, управляемые поля |
| Маска телефона: удаление префикса возвращает «+7 (» | Сравнение с обрезанным значением | Сравнивать с сырым вводом, учитывать позицию курсора (`maskRuPhoneEdit(input, caret)` + `useLayoutEffect`) |
| zod со всеми локалями попал в браузер (~90 КБ gzip) | Клиентская форма импортирует константы из файла со схемой zod | Константы и типы — в отдельном файле без zod; схема — только на сервере |
| `quality={70}` у `next/image` молча становится 75 | Next 16 принимает качество только из `images.qualities` (по умолчанию `[75]`) | `images: { qualities: [70, 75] }` |
| Файл шрифта latin-ext 28 КБ грузится ради «₽» | Срезы Google Fonts с `unicode-range`, ₽ (U+20BD) входит в latin-ext | Одно подмножество на семейство через fontTools; тест покрытия символов |
| fontTools падает с `KeyError: '.notdef'` | `instancer` до `subset` на ленивой `gvar` | Сначала `subset`, сохранить в буфер, затем `instantiateVariableFont` |
| Переход по якорю на телефоне промахивается на ~940 px | `content-visibility: auto`: высоты блоков выше цели — оценки | Перед переходом (клик по `a[href^="#"]` в фазе захвата, `hashchange`, заход с `#`) — `data-full-layout` и полная раскладка |
| После «Показать вилку цены» результат квиза пустой: карточка есть в разметке, но прозрачная | React при смене вида переиспользовал старый узел (строку прогресса) и только добавил ему класс `reveal`; скрипт появления ловил лишь добавленные узлы | MutationObserver с `attributes: true, attributeFilter: ['class']` — элемент, получивший `reveal`, ставится под наблюдение |
| e2e «зелёные», а человек не видит блок | `toBeVisible` в Playwright считает видимым элемент с `opacity: 0` | Помощник `expectSeen()`: непрозрачность элемента и всех предков, `scrollIntoViewIfNeeded`, ожидание перехода |
| iPhone: курсор в поле окна рисуется ниже поля и уезжает при прокрутке окна | Ошибка iOS 26: поле в фиксированном контейнере при большой прокрутке страницы (WebKit 300690 → 300952) | Пока окно открыто, фиксировать страницу: `body { position: fixed; top: -scrollY }`, после закрытия `scrollTo({ top, behavior: 'instant' })`; в `useLayoutEffect`, со счётчиком для вложенных окон |
| В полном номере новая цифра в начале сдвигает номер | Маска оставляла первые 10 цифр после вставки в любом месте | Передавать в маску прежнее значение: если номер полный и цифр стало больше — правку не принимать, курсор оставить на месте |
| Ховер карточки не работает | `.reveal` и `.card-hover` на одном элементе — правило появления перебивает `transform` | Появление на обёртке (`<li>`), ховер на карточке внутри |
| Скрытая нижняя панель находится `getByRole` (strict mode violation) | `translate` и `opacity` не убирают элемент из дерева доступности | `invisible` + `inert` у скрытого состояния |
| e2e с заявками падают в зависимости от порядка | Лимит частоты 5 заявок с одного IP | Фикстура: свой `x-forwarded-for` для каждого теста |
| Тест на точность прокрутки ловит середину анимации | Плавная прокрутка из `scrollTo` наложилась на клик | Ждать стабильный `scrollY`; перезагружать страницу или `behavior: 'instant'` |
| `pkill -f next` убил собственную оболочку | Шаблон совпал с командной строкой оболочки | Искать PID через `ps -eo pid,args \| grep next-server` и убивать по PID |
| Lighthouse локально показывает LCP 3,5 с, а на Vercel меньше | `next start` отдаёт HTTP/1.1, модель Lighthouse завышает время | Мерить через HTTP/2-прокси, два режима, медиана 5 прогонов |
| LCP в симуляции скачет 2,25 / 2,7 с | Гидратация иногда стартует до кадра с фото и попадает в модель | Сравнивать медианы и режим `devtools`; это не реальная задержка |
| `experimental.inlineCss` ухудшил LCP | Больше HTML на критическом пути | Не использовать в продакшене |
| Баннер cookie не появлялся снова после «Настройки cookie» | Локальное состояние `closed` в компоненте | Выбор только в хранилище + копия в памяти; `resetConsent()` шлёт событие |
| Ссылка атрибуции на карте меньше 44 px | Ссылка поверх карты мелким шрифтом | Вынести под карту полноразмерной ссылкой |
| PDF ломается в просмотрщиках iOS и Telegram | Вариативные woff2 встраиваются как Type 3 | Статические TrueType для PDF; тест `pdffonts` |
| canonical и sitemap указывают на localhost | Нет `NEXT_PUBLIC_SITE_URL` при сборке | Ронять сборку в `client` без переменной |
| На Vercel каждая заявка в режиме client — ошибка | Файловая система только для чтения | `LEADS_FILE=off` + CRM или сервер в РФ |
| Нижняя панель на телефоне закрывает 7% экрана, стрелка обрезана | Панель во всю ширину с дублями звонка и мессенджера | Одна капсула «Рассчитать стоимость» по ширине текста; звонок и мессенджер — в шапке |
| Документы (README, PLAN) расходятся с кодом | Решения заказчика не записывались | Журнал решений с датами в `CLAUDE.md`; при каждой задаче — сверка документов |
| PDF из Chrome «ломается» в части просмотрщиков: буквы пропадают или подменяются | Skia даёт разным подмножествам одного шрифта одну метку (`AAAAAA+Onest-Regular` три раза), а ISO 32000-1 п. 9.6.4 требует разных | После `page.pdf()` переименовать метки той же длины (смещения xref не меняются), тест: имена `BaseFont` шрифтов Type0 уникальны |
| PDF-смета после заявки по монолитному проекту отдаёт 500 | Смета знала только каркас из бруса и бросала исключение | Разделы сметы с полем `frame` (`timber`/`concrete`), тест по всем стилям × пакетам × площадям |
| Клик по фото карточки проекта ничего не делает, над фото обычный курсор | «Растянутая» кнопка (`after:absolute inset-0`) упёрлась в ближайший `absolute`-родитель — нижнюю плашку, а стрелка с `transform` перекрыла кнопку | Щелчок на всю карточку (`onClick` на `<article>`), кнопка с названием для клавиатуры; тест: `elementFromPoint` над фото — `cursor: pointer`, клик по фото и стрелке открывает окно |
| После удаления блоков первого экрана баннер cookie закрыл кнопки | Содержимое первого экрана прижато к низу (`justify-end`), а текст баннера стал длиннее | На телефоне содержимое сверху (`justify-between`), текст баннера 13 px; тест на перекрытие при 375×740 |
| Тест лоадера падает только в полном прогоне | Отсчёт шёл с появления элемента в HTML, а CSS под нагрузкой приходит позже | Начинать отсчёт после `toHaveCSS('position', 'fixed')` |
| Текст на сайте обещает то, чего нет в договоре | Тексты писались отдельно от договора | Сверка оффера с договором; e2e-страж на старые формулировки |
