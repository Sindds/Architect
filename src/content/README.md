# Что где менять: данные, тексты, картинки

Всё, что меняется под заказчика, лежит в этой папке `src/content/`. Код компонентов трогать не нужно.

| Файл | Что в нём | Менять под заказчика |
|---|---|---|
| **`company.ts`** | Данные компании: название, телефон, почта, адрес и точка на карте, часы, мессенджеры, реквизиты, обработчики данных, образцы документов | **Обязательно** (поля с пометкой «ЗАМЕНИТЬ») |
| **`texts.ts`** | Все тексты страницы: меню, заголовки блоков, первый экран, кнопки, формы и ошибки, квиз, калькулятор, этапы, преимущества, вопросы и ответы, футер, баннер cookie, страница 404 | По желанию |
| **`media.ts`** + папка **`images/`** | Все картинки: фото, визуализации, чертежи, портреты, карта — и подписи к ним (alt) | По желанию; портреты — фото сотрудников заказчика |
| `projects.ts` | Проекты домов: название, площади, этажи, описание, особенности, конструктив, помещения, картинки | По желанию |
| `people.ts` | Команда (имя, должность, чем занимается, фото) и отзывы | Да: настоящие сотрудники и отзывы со ссылкой на источник |
| `pricing.ts` | Цены за м², пакеты (название, описание, что входит), опции, сроки | По прайсу заказчика |
| `estimate.ts` | Позиции подробной сметы в PDF | По прайсу заказчика |
| `legal.ts` | Политика конфиденциальности, согласие на обработку данных, cookie — реквизиты подставляются из `company.ts` | Читает юрист заказчика |
| `variants.ts` | Рекламные варианты первого экрана (`/?v=…`): какая картинка и какой проект первыми; заголовки — в `texts.ts` | Под рекламные кампании |

Служебные файлы, их править не нужно: `site.ts` (собирает настройки), `types.ts` (описание полей), `estimate-sample.ts` (дом для образца сметы).

## Как править, чтобы ничего не сломать

- Меняйте только текст между кавычками `'…'` или `` `…` ``. Кавычки, запятые и скобки оставляйте.
- `${…}` внутри текста — подстановка (цена, срок, площадь, название). Её можно переставить в другое место фразы, но не удалять.
- Цены и сроки руками не пишут: их считает `src/lib/pricing.ts` по ставкам из `pricing.ts`.
- «Вы», «Ваш» — с заглавной буквы.
- Апостроф внутри текста в одинарных кавычках ломает строку: используйте «ёлочки» или замените кавычки строки на обратные `` ` ``.

## Картинки

1. Положите новый файл в `src/content/images/` **под тем же именем**: он заменит старый везде на сайте.
2. Поправьте подпись (alt) в `media.ts`: что изображено, для незрячих посетителей и поисковиков.
3. Другой формат (`.jpg`, `.png`) — поменяйте расширение в строке `import` в `media.ts`.
4. Размеры: фото и чертежи горизонтальные, не меньше 1400×770 px; портреты вертикальные, около 640×850 px. Сайт сам сжимает картинки и отдаёт телефону уменьшенную копию.

## После правок

```bash
pnpm map:preview    # после смены geo в company.ts — картинка карты в футере
pnpm docs:pdf       # после смены цен, реквизитов, этапов — образцы договора и сметы
pnpm seo:images     # после смены фото первого экрана, цен или логотипа — картинка для соцсетей
pnpm ready          # что ещё не заполнено и не настроено для публикации
pnpm check          # проверка: типы, стиль текстов, цены в разметке, юнит-тесты
```
