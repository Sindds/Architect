# ARCLINE — лендинг архитектурно-строительного бюро (Next.js + Payload CMS)

Цель: превратить прототип из `legacy/` в одностраничный лендинг уровня 150 000 ₽+ — с работающими заявками, настоящей админкой, вариантами под рекламу, высокой скоростью и соблюдением 152-ФЗ.
План работ: `docs/PLAN.md`. Задачи выполняются строго по порядку, по одной. Контент, цифры и запреты: `docs/CONTENT-SPEC.md`.

## Стек
Next.js (App Router, TypeScript strict) — версия, совместимая с Payload 3 (по документации Payload: 15.4.11–15.4.x или 16.2.6+; перед началом сверь с payloadcms.com/docs/getting-started/installation) · Payload CMS 3 + Postgres · Tailwind CSS v4 · zod · Vitest · Playwright + @axe-core/playwright · pnpm · Node 20.9+.

## Правила (обязательны)
1. Одна задача из PLAN.md за раз. Порядок: 1) кратко опиши план и список файлов, 2) реализуй, 3) выполни все проверки из пункта «Готово, если» и покажи их вывод, 4) сделай коммит `[ID] краткое описание`. К следующей задаче не переходи без команды.
2. Единый источник правды. Цены, сроки, контакты, реквизиты и тексты блоков берутся только из Payload (collections и globals). Цены и сроки считает только `src/lib/pricing.ts`. В JSX нельзя хардкодить цены, сроки, телефоны и адреса.
3. `legacy/` только для чтения. Это референс по структуре и визуалу; код оттуда не импортировать. Переносить, переписывая.
4. Весь видимый текст на русском (168-ФЗ). Декоративные английские подписи вроде «VIP», «// ROADMAP» или «OFFICIAL VERIFIED» запрещены.
5. Чёрный список утверждений — в `CONTENT-SPEC.md`, раздел 2. Нельзя выдумывать ИНН, ОГРН, номера документов, рейтинги, «подтверждённых владельцев» и реальные названия посёлков.
6. Режима «концепт» нет (решение заказчика 19.10.2026): один рабочий режим, индексация открыта, заявки уходят в настроенные хранилища. Данные компании в шаблоне — заглушки (нули, `example.com`), под заказчика их меняют по README «Под нового заказчика»; заглушки не попадают в разметку schema.org.
7. Секреты хранятся только в серверных env, без `NEXT_PUBLIC_`. Персональные данные из заявок сохраняются только в серверных хранилищах (почта, Битрикс24, 1С, файл на сервере; БД — после Payload). В Telegram уходят только номер заявки, источник и ссылка на карточку в CRM, без имени и телефона.
8. Доступность по WCAG 2.2 AA: контраст ≥ 4,5:1, кликабельные цели ≥ 44 px на мобильном, связка label↔input, работа с клавиатуры, поддержка `prefers-reduced-motion`.
9. Запрещены: `import * as` из библиотек иконок, предзагрузка всех картинок, анимация появления LCP-элемента. Прелоадер разрешён решением Дмитрия от 08.10.2026 только в текущем виде (`src/components/PageLoader.tsx`): один раз за сессию, без фейкового прогресса, не показывается при reduced motion, без JS исчезает сам.
10. Для UI-решений используй скилл `ui-ux-pro-max`, если он установлен. Любой шрифт перед использованием проверяй на наличие подмножества `cyrillic`.
11. Это **лендинг**: одна страница `/` (плюс статические варианты `/v/[variant]` под рекламу). Отдельных страниц проектов не делать — только модальные окна со ссылкой `/?project=slug` (блока кейсов нет с 17.10.2026). Кроме этого существуют только юридические страницы, 404 и служебные `/api/health`, `/smeta/<токен>`, `robots.txt`, `sitemap.xml`, `llms.txt`.
12. Если задача требует решения, которого нет в плане, или план противоречит документации библиотеки — остановись и спроси.
